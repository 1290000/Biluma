# Biluma · 羽哩

基于 [BiliPai](https://github.com/jay3-yy/BiliPai) 独立维护的第三方 Bilibili Android 客户端。希望通过精简设置和非必要功能，逐步形成更明确的默认行为与界面体验。

[English](README_EN.md) · [项目主页](https://github.com/1290000/Biluma) · [问题反馈](https://github.com/1290000/Biluma/issues) · [版本发布](https://github.com/1290000/Biluma/releases)

> **项目处于改造初期，尚无 Biluma 独立发行版。** 首轮九项界面与设置精简已在源码中实现，尚未通过测试、编译或真机验证。本项目不是 BiliPai 原作者或哔哩哔哩的官方发行版。

## 项目身份

中文名「羽哩」结合了羽毛笔与哔哩哔哩的名称元素，英文名及仓库名为 **Biluma**。桌面名称统一使用英文；名称灵感不代表相关权利方的授权或官方关联。

| `:app` 变体 | 桌面名称 | 安装包名（`applicationId`） |
| --- | --- | --- |
| 正式版 `release` | `Biluma` | `com.biluma.app` |
| 测试版 `dev` | `Biluma Dev` | `com.biluma.app.dev` |

两个包名用于区分正式版与测试版，也与 BiliPai 原版隔离；应用私有数据不会自动迁移。源码命名空间仍为 `com.android.purebilibili`，不需要为更换安装包名而全面重命名源码。

这些配置仅适用于主应用 `:app`。保留的 `app-tv` 模块尚未纳入 Biluma 品牌迁移，是否保留或改造需另行确定。

## 界面精简进度

本轮九项已分批实现并合并到 `main`。下表区分已确认目标与源码实现进度，不代表已发布或通过运行验证。

| 项目 | 固定目标 | 源码状态 |
| --- | --- | --- |
| 1. 界面预设 | 仅 Miuix，清理 MD3 专用界面 | 已实现；删除用户可见的界面预设入口和相关资源，运行时固定为 Miuix；Material 3 基础设施仍保留作兼容与回退 |
| 2. 液态玻璃 | 开启，保留非玻璃界面和兼容/性能回退 | 已实现；删除全局开关、搜索入口和旧备份分享项，运行时固定开启；不支持设备仍使用非玻璃回退 |
| 3. 选项弹窗样式 | 跟随选项弹出 | 已实现；删除居中单选弹窗、设置入口和偏好读写 |
| 4. 开屏图标遮罩动画 | 关闭 | 已实现；删除开关、启动动画样式和专用资源，系统启动图标固定透明；保留系统启动背景、预加载及桌面图标兼容入口 |
| 5. 使用原生 Miuix 弹窗 | 开启 | 已实现；删除开关及关闭时的替代路径，Miuix 对话框不再由该开关回退到 Material |
| 6. 视频标签大小 | 更小 | 已实现；视频简介标签固定更小，删除选择入口、偏好、备份字段和未使用的中间尺寸；保留其他标签的标准尺寸 |
| 7. 紧凑播放器控件 | 开启 | 已实现；删除开关、偏好及经典布局分支，固定紧凑间距与遮罩，分享保留在「更多」菜单 |
| 8. 悬浮底栏 | 开启 | 已实现；删除开关、偏好、旧备份字段和贴底渲染路径，保留搜索联动、视频小横条及大屏侧栏 |
| 9. 导航图标交叉缩放 | 开启 | 已实现；删除开关及关闭分支，图标在指示器过渡期间缩放，停稳后恢复原始大小 |

本轮九项均不再提供用户选择入口，已删除对应专用分支和失效子选项；旧主题键与液态玻璃开关键仍保留必要的迁移兼容边界，但运行时固定使用 Miuix 和液态玻璃。确认/输入对话框、滑块弹窗和折叠屏安全布局不属于本批删除范围；Material 3 基础设施与不支持设备的非玻璃回退也暂不删除。

## 已固定的播放行为

- 不再弹出跨分 P／合集续播建议；保留播放历史和当前视频历史进度恢复。
- 视频简介默认展开，仍可手动收起；视频笔记默认只显示入口，点击后查看完整笔记列表，保留「显示视频笔记」设置。
- 取消双击点赞，保留普通点赞和其他双击播放手势。
- 亮度手势仅调整当前播放窗口，不修改系统亮度，也不申请修改系统设置权限。
- 设置页不再显示「评论 IP 属地」说明，评论中的属地仍在有数据时正常显示。

上述选项的设置入口、搜索词、偏好读写和专用逻辑已清理；旧偏好不再参与行为判断，设置分享导入会跳过废弃字段。本批改动仅做静态检查，回归测试代码已更新但未运行。

## 已固定的首页与导航行为

主应用不再提供以下开关，旧偏好、设置分享与备份恢复不能改变这些行为：

- 首页顶部轮播封面关闭，推荐页直接显示完整普通视频流；轮播默认播放及专用实现一并移除。
- 底栏搜索联动开启，首页顶部搜索条保留；下滑不再触发搜索、导航与播放条合体。
- 收藏、历史、稍后再看在支持底栏页内搜索的主导航页面使用精简搜索，关键词仍可查看和清除。独立搜索页、侧栏模式及没有可用底栏搜索入口的列表保留顶部搜索入口。
- 侧边栏账号切换入口始终提供，但不强制开启侧边栏。

同时移除不再使用的旧底栏搜索自动展开模式与布局模式。仍在使用的搜索输入、搜索页转场、播放条状态切换和共享导航视觉保留；没有调整 `app-tv`。此批修改已补充测试代码并做静态检查，尚未运行测试、编译或真机验证。

## 外观与提示设置精简

- 列表条目固定跟随当前界面风格，主应用目前固定使用 Miuix，不再提供独立样式覆盖。
- 启动动画样式选择已移除；与主干一致，不播放图标飞出或女仆欢迎动画，仅保留系统启动背景和预加载。
- 移除开屏壁纸、随机壁纸及专用选择、裁剪、随机池配置。保留首页壁纸和个人空间背景；旧首页背景若依赖开屏壁纸，则迁移为独立首页壁纸，不删除其图片文件。
- 画质降档诊断弹窗固定仅提示一次，保留已有提示记录和诊断弹窗总开关；弹窗内不再提供重复提示选项。
- 视频详情评论标签始终显示评论数。旧偏好在读取前迁移清理，不再导出被移除的选项，旧备份也不能恢复这些行为。

本次精简只完成源码调整和静态检查，已更新并补充回归测试，但未运行 Gradle 测试、编译、打包或真机验证。其他功能精简与新品牌视觉不在本批范围。

## 已固定的视频行为

以下仅适用于主应用 `:app`，相应设置开关和专属偏好读写已移除：

- AI 总结入口始终显示，仍由用户点按查看，不自动展开。
- 视频笔记进入每个视频时保持收起，点按笔记入口打开抽屉；保留「显示视频笔记」开关及笔记查看、编辑和分页功能。
- 普通竖屏视频入口先进入详情页，不自动直达刷视频；仍可手动进入竖屏刷视频。
- 竖屏刷视频允许横竖屏混合推荐，不再为纯竖屏筛选额外请求视频方向。
- 普通启动不自动进入竖屏视频流；使用须知门禁和外部链接导航仍保留。

旧偏好不再控制这些行为，旧设置备份中的对应项会跳过，新的设置导出不包含这些项。本轮仅完成静态检查，回归测试已更新，未运行 Gradle 测试、编译、打包或真机验证。

## 开发与构建参考

开始修改前阅读 [AGENTS.md](AGENTS.md)。它说明仓库边界、修改约束、验证授权和提交约定；文档示例不是自动执行构建的授权。

当前配置使用 **JDK 21、AGP 9.3.1、Gradle 9.5.0、Kotlin 2.4.0、compileSdk 37**；主应用最低系统版本为 **Android 8.0 / API 26**。配置来源分别为 [版本目录](gradle/libs.versions.toml)、[Gradle wrapper](gradle/wrapper/gradle-wrapper.properties) 与应用构建文件。

部分 Miuix 依赖来自 GitHub Packages，需要通过用户级 Gradle 属性 `gpr.user` / `gpr.key` 或环境变量 `GITHUB_ACTOR` / `GITHUB_TOKEN` 提供具备相应读取权限的凭据。不要将凭据写入仓库。

开发者明确选择生成本地可安装测试包时，使用 Dev 变体：

```powershell
.\gradlew.bat :app:assembleDev
```

macOS / Linux 对应命令为 `./gradlew :app:assembleDev`。不打包、安装或交付 debug / smooth APK；正式 Release 发布还需完成独立签名和发布流程配置。

当前脚本配置的 Dev 导出路径为 `app/build/outputs/bilipai/dev/BiliPai-<versionName>-dev.apk`，Release 对应 `app/build/outputs/bilipai/release/BiliPai-<versionName>.apk`。这是尚未迁移的上游命名，不是已生成的产物；`<versionName>` 取主应用的基础版本名。Gradle 根项目名也仍为 `BiliPai`。
